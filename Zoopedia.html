Zoopedia

Zoopedia is an educational and informative website I developed as part of a formative assignment. It allows users to compare zoos and wildlife parks based on pricing, animals, and features.

Features

  • Animal listings by location
  • Responsive and structured layout
  • Zoo comparison system
  • Educational browsing experience

Technology Stack

HTML, CSS, Responsive Layouts
