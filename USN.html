USN Mobile Fitness App Wireframing Project

The USN Mobile Fitness App Wireframing project involved creating a fitness tracking app for USN customers.

Overview

The app allows users to track fitness, set goals, and monitor progress over time.

Features

  • Fitness tracking system
  • Clean structured navigation
  • Newsletter integration concept
  • Diet planning and calorie tracking
