Garden - E-commerce Webpage

Garden is an e-commerce website for a garden store. It features a responsive design, product listings, and shopping cart functionality.

Overview

Garden provides users with tools and gardening products in a structured online store experience.

Features

  • Separate pages for plants, tools, and pet-friendly plants
  • Contact form for customer communication
  • Product filtering system using tags

Technologies used: HTML, CSS, JavaScript, PHP
