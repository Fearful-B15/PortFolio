Georage Bakery Website

Georage Bakery is a fully functional bakery website that includes a product catalog, shopping cart, and checkout system. It focuses on responsive design and JavaScript-powered interactivity.

Features

  • Product catalog with bakery items
  • Dynamic shopping cart
  • JavaScript-powered pricing updates
  • Responsive UI design
  • Checkout flow (demo system)

Technology Stack

HTML, CSS, JavaScript, Responsive Design
